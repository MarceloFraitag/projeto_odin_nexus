# Sign-up Form — The Odin Project

**English Version | Versão em Português**

---

## English

Sign-up form developed as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

The project focuses on practicing HTML forms, page layouts using CSS Flexbox and CSS Grid, custom typography, and native form validation.

### Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Grid, Custom Properties)
- Custom typography (`@font-face`)

### Features

- **Split-screen layout:** Image sidebar with Odin branding alongside the registration form.
- **Native form validation:** HTML attributes such as `required`, `type="email"`, and `minlength` to validate user input.
- **Visual feedback:** CSS pseudo-classes (`:focus` and `:user-invalid`) to highlight focused and invalid fields.
- **Organized form structure:** Input fields arranged in a two-column grid, with a separate submission footer.
- **Photo attribution:** Credit to Halie West, with a direct link to the original photograph on Unsplash.

### How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/MarceloFraitag/projeto_odin_nexus.git
   ```

2. Open the project directory.

3. Make sure the following files are available in the project root:
   - `index.html`
   - `style.css`
   - `plantas.avif`
   - `odin-lined.png`
   - `Norsebold.otf`

4. Open `index.html` in your browser or use the Live Server extension in VS Code.

### Notes

This is a front-end practice project. The form uses native browser validation but does not include a backend or user account creation.

Password confirmation matching is not implemented.

## Português

Formulário de cadastro desenvolvido como parte do currículo do [The Odin Project](https://www.theodinproject.com/).

O projeto tem como objetivo praticar formulários HTML, construção de layouts com CSS Flexbox e CSS Grid, tipografia personalizada e validação nativa de campos.

### Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, CSS Grid, Variáveis CSS)
- Tipografia personalizada (`@font-face`)

### Funcionalidades

- **Layout dividido:** Barra lateral com imagem de fundo e identidade visual do Odin, acompanhada pelo formulário de cadastro.
- **Validação nativa:** Utilização de atributos HTML como `required`, `type="email"` e `minlength` para validar os dados inseridos.
- **Feedback visual:** Pseudoclasses CSS (`:focus` e `:user-invalid`) para destacar campos selecionados e inválidos.
- **Organização do formulário:** Campos distribuídos em duas colunas utilizando CSS Grid, com o rodapé de envio separado visualmente.
- **Créditos da fotografia:** Atribuição à fotógrafa Halie West, com link direto para a imagem original no Unsplash.

### Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/MarceloFraitag/projeto_odin_nexus.git
   ```

2. Abra a pasta do projeto.

3. Verifique se os seguintes arquivos estão na raiz do projeto:
   - `index.html`
   - `style.css`
   - `plantas.avif`
   - `odin-lined.png`
   - `Norsebold.otf`

4. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server do VS Code.

### Observações

Este é um projeto de prática front-end. O formulário utiliza a validação nativa do navegador, mas não possui backend nem funcionalidade de criação de contas.

A comparação entre os campos de senha e confirmação de senha não foi implementada.
